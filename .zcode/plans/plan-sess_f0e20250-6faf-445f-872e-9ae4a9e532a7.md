# 新增「羊了个羊」小游戏页面

## 新建 `src/views/games/YangGame.vue`

参照同目录 `Game2048.vue` 的既有风格：`<script setup>`（纯 JS）+ `<style scoped>`、主题 CSS 变量、localStorage 存最佳记录、失败/胜利 overlay、`@media (max-width: 480px)` 移动端适配。

**核心玩法（牌堆堆叠 + 7 格槽位三消）：**

1. **数据结构与渲染**：每张牌 `{ id, type, layer, x, y, state }`，绝对定位 + zIndex 按层递增；牌面用 emoji（🐑🥕🌽🍄🌻🧣☔🌙⭐🍀…），无需图片素材。牌尺寸与层间偏移由 JS 根据容器宽度计算（监听 resize），保证手机端可玩。
2. **关卡生成（三档难度，开局可选）**：
   - 简单：4 层，每层 3×3=9 张，6 种牌面
   - 普通：6 层，每层 4×3=12 张，9 种牌面
   - 困难：8 层，每层 4×3=12 张，12 种牌面
   - 每层网格相对下层错位半格形成堆叠覆盖；总牌数与每种牌的数量均保证为 3 的倍数（必然可消完）。
3. **点击规则**：某张牌可点击 ⇔ 更高层没有任何未消除的牌与其矩形重叠（相交检测）；被压住的牌加深色遮罩。点击后牌以 CSS transition 飞入槽位。
4. **槽位栏（7 格）**：新牌插入到末尾连续同类牌之后（同类自动聚拢）；凑满 3 张同类即播放消除动画并前移补位；槽满 7 张且未消除 → 失败；场上与槽位全部清空 → 通关。
5. **三个经典道具**（每局限定次数，用完置灰）：
   - 撤销 ×1：槽位最后一张牌放回原位
   - 洗牌 ×1：场上剩余牌的牌面随机重排
   - 移出 ×1：槽位前 3 张移入「暂存区」（不占槽位、不可再操作），腾出槽位
6. **信息区与记录**：标题、剩余牌数、最佳通关用时（localStorage `yang_bestTime`）、重来按钮。
